# Manual featured-section toggle for episodes vs shows

Hero sekcija na početnoj strani ručno se podešava preko konfiguracije/CMS-a (`featured_section: episodes | shows`). Kad budu postojale predstave, moći će da se naglasi sekcija koju brend trenutno promoviše. Automatsko prebacivanje na osnovu broja stavki odbijeno je jer prag može da promaši nameru i izazme neočekivane promene prikaza.
