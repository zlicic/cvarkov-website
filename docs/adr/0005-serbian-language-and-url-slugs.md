# Serbian Latin script only and Serbian URL slugs

Sajt koristi isključivo srpsku latinicu, bez engleske verzije. URL-ovi stranica su na srpskom jeziku (`/serija`, `/predstave`, `/o-djordju`, `/kontakt`) jer je ciljna publika region i dijaspora koja govori srpski. Dvojezičnost i engleski slugovi bi dodali kompleksnost bez srazmerne koristi u MVP-u.
