# Markdown/JSON content collections instead of a headless CMS

Sadržaj se u MVP-u drži u Markdown/JSON fajlovima unutar Astro Content Collections. To izbegava troškove i održavanje CMS-a u ranoj fazi, kada je učestalost ažuriranja jednom nedeljno i ažurira ih tehnička osoba. Kada sadržaj poraste ili više ljudi treba da uređuje, prelazimo na cloud headless CMS (npr. Sanity, Contentful).
