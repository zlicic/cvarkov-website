# Astro + React static site on Namecheap shared hosting

Za MVP smo odabrali Astro sa React ostrvima i statičkim izlazom. Namecheap shared hosting ne podržava Node.js backend, pa Strapi/Next.js SSR nisu bili opcije bez dodatnog servera. Astro omogućava React komponente tamo gde je interakcija potrebna, a većina sajta ostaje statički HTML koji se uploaduje preko FTP-a.
